# ~ Temp Cleaner ~

Create temporary files and manage them the correct way, works and helps. Using temp-cleaner you don't have to trust a sloppy, AI stuffed Operating System to do the job and you're able to use some simple piece of OSS. :)
When finished Temp Cleaner will include some nice features like better deletion control and re-creation of files on e.g. sudden shutdowns

Temp Cleaner is and will be/stay a CLI tool, meaning it will run in your terminal and does not include any GUI
